# SQL Data Validation

## Project Overview

SQL testing focused on validating data persistence and consistency between API responses and database records.

## Scope

The project covered:

- Data persistence after form submission
- Validation of database records
- Comparison of API responses with database data
- Basic SQL queries for data verification

## SQL Skills

- SELECT
- WHERE
- JOIN
- GROUP BY
- Filtering and data comparison

## Results

- 10+ SQL queries created
- API data compared with database records
- 3 data discrepancies identified

## Example Checks

The project included checks for:

- Correctly saved user data
- Matching API and database values
- Missing or inconsistent records
- Data returned for specific conditions

## Tools

- SQL
- Test database
- Postman
